# Carunit Floating Cart (سبد شناور کاریونیت)

Lightweight, RTL/Persian floating cart for WooCommerce, themed for carunit.ir (Woodmart black & yellow).

- Floating button + slide-in mini-cart panel (WooCommerce fragments, no extra requests)
- Persian digits on the count badge
- Settings: top-level admin menu "سبد شناور" (also linked from the Plugins list) (position, color, hide on cart/checkout, open on add)
- Requires WooCommerce, PHP 7.4+

## Install
Zip the folder `carunit-floating-cart` and upload via Plugins → Add New → Upload.
